# Журнал сбора

Дата сбора: **2026-11-04**. Часовой пояс дат в API — UTC; даты в наборе приведены к `YYYY-MM-DD`.

## 1. Постановка и границы

- Цель: собрать 100–200 реальных публикаций о проблемах с зависимостями, очисткой пакетов и местом на диске в Linux.
- Запрещено: придумывать публикации, пользователей, голоса и цитаты; обходить CAPTCHA/анти-бот; выдавать оценки востребованности.
- Обязательные требования: рабочий URL, отсутствие дубликатов, фиксация даты и вовлечённости, разделение прямых запросов визуализации и косвенно связанных проблем.
- Приоритет: пользовательские обсуждения, а не реклама, анонсы и статьи разработчиков.

## 2. Reddit

1. Прямой Reddit API вернул `403`, поэтому использован публичный архив **Arctic Shift** (`https://arctic-shift.photon-reddit.com/api/posts/search`).
2. Reddit RSS был проверен как альтернатива, но работал нестабильно и слишком медленно; от него отказались.
3. Запросы: 6 основных по 8 сабреддитам + 12 дополнительных. Успели сохранить 13 поисковых выдач; после дедупликации — **410 уникальных постов**.
4. После исключения удалённых/скрытых (`[removed]`, `[deleted]`, флаг removal) осталось **351 живых постов**.
5. Архив периодически отвечал `422 {"data":null,"error":"Timeout. Maybe slow down a bit"}`. Повторы с паузами; часть запросов не завершилась. Сбор остановлен, когда пула стало достаточно.
6. Для набора отобраны **46** постов. Оценки и комментарии — снимок Arctic Shift, не live-значения Reddit.
7. Исключены саморекламные посты:
   - `1ujnn4j` — анонс инструмента «labeled»;
   - `1r4t6jc` — анонс собственного TUI для поиска неиспользуемых пакетов.

## 3. Stack Exchange

1. Использован официальный API 2.3, метод `search/advanced`, параметр `filter=withbody`.
2. 22 запроса к двум сайтам: `askubuntu` и `unix`.
3. После дедупликации — **1 020 вопросов**; отобраны **42**: 25 Ask Ubuntu и 17 Unix & Linux.
4. Для Stack Exchange поле `comments_count` заполнено числом ответов (`answer_count`), потому что комментарии отдельно не собирались. Это зафиксировано в словаре.
5. `score` — рейтинг вопроса на момент вызова API.

## 4. Fedora Discussion

1. Использован публичный Discourse API: `search.json` и `t/{id}.json`.
2. 14 запросов; найдено **600 topic id**.
3. Детали первой публикации загружены для **215 тем**. Сбор остановлен: отобранный пул уже покрывал целевые категории, оставшиеся темы не добавляли новых типов проблем. Это не полная выборка всех найденных тем.
4. Для набора отобраны **20** тем.
5. `comments_count` = `posts_count - 1`, `score` = `null`: лайки Discourse не приравнивались к голосам.

## 5. GitHub

1. Использован GitHub Search API по issues: 12 общих запросов и 9 запросов по репозиториям.
2. После дедупликации — **779 issue**; отобраны **20**.
3. Rate limit неавторизованного Search API был исчерпан; API вернул `403`, после чего сбор остановлен. Дополнительные запросы не выполнялись.
4. `score` = `null`: реакции GitHub не приравнивались к голосам. `comments_count` = число комментариев issue.
5. В выборку вошли issue из `rpm-software-management/dnf5`, `Morganamilo/paru`, `Jguer/yay`, `oguzhaninan/Stacer`, `bleachbit/bleachbit`, `mvo5/unattended-upgrades`, `linuxmint/mintupdate`, `mvo5/synaptic`.

## 6. Arch Linux Forums

1. Первый прогон поиска был слишком частым: форум начал отдавать `At least 60 seconds have to pass between searches`, а часть выдачи оказалась нерелевантной (свежие темы вместо результатов поиска). Результаты первого прогона не использовались.
2. Второй прогон: 6 запросов только по заголовкам (`unused`, `orphan`, `dependency`, `autoremove`, `disk space`, `clean`) с паузой **65 секунд**.
3. Получено **140 уникальных тем**. Поиск FluxBB даёт широкие совпадения, поэтому многие темы были о железе, сборке или AUR-сопровождении; они не включались.
4. Отобраны **6** тем, непосредственно относящихся к зависимостям, orphan-пакетам, конфликтам обновления и удалению.
5. `score` = `null`, `comments_count` = `replies`.

## 7. Debian User Forums

Попытка получить публичную выдачу не удалась: вместо результатов сайт отдавал JS-заглушку `Loading...` (около 1 233 байт). Обход анти-бот-защиты не выполнялся. Площадка исключена из набора; ограничение зафиксировано.

## 8. Курирование

- Удалены дубликаты по URL; проверено — в итоговом наборе **0** повторяющихся URL.
- Удалены удалённые/недоступные публикации.
- Исключены саморекламные посты Reddit (см. выше).
- Не включались анонсы сопровождения пакетов (maintainer orphan announcements): это не пользовательская очистка.
- Прямые запросы визуализации (граф/дерево/карта) отделены от проблем, где визуализация лишь подразумевается: флаг `mentions_visualization` выставлен только для 8 публикаций.
- Приоритет 2021+: 116 из 134 строк опубликованы в 2021 году или позже; 18 строк 2020 года оставлены как особенно близкие к теме (например, карта зависимостей, очистка сервера, autoremove).
- Для GitHub issue — отдельная публикация; комментарии не считаются отдельными строками.
- Для Fedora и Arch `distro` выставлен по площадке; для GitHub — по целевому дистрибутиву проекта; для Reddit — по явному упоминанию или тематическому сабреддиту. Правила — в `data_dictionary.md`.

## 9. Проверка

- Написан `scripts/build_dataset.py`: он соединяет курированные записи с сырыми метаданными.
- Для каждой строки evidence проверяется как подстрока заголовка или тела после нормализации HTML-сущностей, кавычек, тире, пробелов и регистра.
- Сборка завершается ошибкой, если evidence не найден; при первом прогоне были исправлены 3 цитаты (Reddit `1cdjo89`, `kv7xf5`; Ask Ubuntu `1419062`).
- Итог: **134 записи**, 6 площадок, 0 дубликатов URL, у всех заполнены `comments_count` и `evidence`.
- `score` заполнен для 88 строк; `null` для 46 строк (GitHub 20, Fedora 20, Arch 6).

## 10. Ограничения

- Выборка не репрезентативна и не позволяет оценивать распространённость проблем или востребованность продукта.
- Reddit покрыт только тремя сабреддитами; неанглоязычные сообщества не включены.
- Reddit-метрики — снимок архива; они могут отличаться от текущих.
- Stack Exchange `comments_count` — число ответов, а не комментариев.
- GitHub, Fedora и Arch не имеют сопоставимого рейтинга; межплатформенное сравнение метрик некорректно.
- Fedora: детали загружены не для всех 600 найденных тем.
- Arch: маленькая выборка из-за лимита поиска и широкой выдачи.
- Debian User Forums недоступны без обхода анти-бота; площадка отсутствует.
- Набор фиксирует только публичные высказывания; он не подтверждает и не опровергает гипотезы о спросе.
