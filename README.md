## О сборе данных
Собрал статистику с пачки форумов и собрал их в таблички. Применял скрипты для сбора всего этого и агентов, чтобы убрать лишнее, что на самом деле к теме не относится.
Нашёл несколько аналогов, таблички со сравнением тоже есть. 
Есть почти полный аналог, но даже у него нашёл пару фич, которые я планировал реализации, но которых не видел в нём.
Все данные лежат в research_data/
(Вирусов в проекте нет, честно, можно открывать в Trust mode в VScode)
